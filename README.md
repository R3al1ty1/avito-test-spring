# Тестовое задание Avito

## Описание
API сервис для управления пунктами выдачи заказов (ПВЗ) и приёмки товаров.

## Технологии
- Python 3.12
- FastAPI
- PostgreSQL
- Docker
- Prometheus (для мониторинга)
- Pytest (для тестирования)

## Запуск проекта

### Предварительные требования
- Docker
- Docker Compose
